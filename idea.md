# AI Lab Setup

Chosen repository: https://github.com/lm-space/ai-lab-setup

First project: [Understanding AI](projects/understanding-ai/README.md).

Build a collection of independently runnable AI projects, tools, agents, skills, techniques, and learning resources. TypeScript, Python, Go, and Rust are the implementation tracks. SQLite is the default for future persistent service examples, with optional DuckDB analytics and Docker PostgreSQL when needed.

Understanding AI imports the complete application source of AI Explained Lab and expands it into an observable agent platform: chat, provider calls, instructions, skills, context, tools, MCP connections, retrieval, execution traces and history.

Start with Ollama, OpenAI and Anthropic; preserve the imported OpenRouter and Google adapters. Verify each provider/model combination explicitly. See the [project roadmap](projects/understanding-ai/docs/roadmap.md) for current scope and upcoming work.

New work uses current commit dates. Historical examples will record an as-of date and original source provenance; no historical range has been selected.
